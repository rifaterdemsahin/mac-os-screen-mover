💡 Best Practices & Setup Tips

Recommendations

Practical recommendations for choosing shortcuts, configuring macOS Mission Control, and organizing Virtual Desktops 1–10 without breaking app-level hotkeys.

1. Recommended Hotkey Combination

Use ⌃ Ctrl + ⌥ Option + 1..0 (and keep ⌘ Cmd + 1..9 for Tabs) Mapping ⌃ Ctrl + ⌥ Option + 1..9 to Desktops 1–9 and ⌃ Ctrl + ⌥ Option + 0 to Desktop 10 avoids overriding browser/editor tab switching (⌘ Cmd+1..9) and macOS screenshots (⌘ Cmd+⇧ Shift+3/4/5).

Switch Desktop (Built-in)

⌃ Ctrl + 1..0 jumps your focus directly to Desktop 1–10. Enable these in System Settings → Keyboard → Keyboard Shortcuts → Mission Control.

Move Active Window (This Tool)

Add ⌥ Option (⌃ Ctrl + ⌥ Option + 1..0) to carry the focused window with you to that same Desktop.

3. Recommended macOS Settings

  1. Lock Desktop Order: Go to System Settings → Desktop & Dock → Mission Control and turn OFF "Automatically rearrange Spaces based on most recent use". This keeps Desktops 1–10 in fixed positions.
  2. Reduce Motion (Optional): Enable System Settings → Accessibility → Display → Reduce motion to make Space switching feel snappier with cross-fade instead of sliding animations.
  3. Choose Follow vs. Stay Put: Keep FOLLOW_WINDOW = true in init.lua when moving an app you are about to work in; set FOLLOW_WINDOW = false if you mostly clean up stray windows while staying on your current Desktop.

4. Example 1–10 Desktop Layout

Assigning fixed roles to numbered Desktops builds muscle memory so you never have to scan Mission Control thumbnails:

  • Desktop 1 (⌃⌥1): Primary Browser & Docs
  • Desktop 2 (⌃⌥2): Code Editor / IDE
  • Desktop 3 (⌃⌥3): Terminal / Logs / Dev Servers
  • Desktop 4 (⌃⌥4): Chat, Email & Calendar
  • Desktop 5–9 (⌃⌥5–9): Secondary projects, design tools, databases, or test browsers
  • Desktop 10 (⌃⌥0): Music, notes, or background dashboards
