Mental Model & Motivation

First Principles: Why I Use This

When you work across many macOS Virtual Desktops (Spaces), windows inevitably pile up in the wrong places. This project exists to make re-sorting your windows across desktops instant, deterministic, and 100% keyboard-driven.

1. The Reality of Working with Many Virtual Desktops

Virtual Desktops (Spaces) on macOS are great for separating contexts—one Space for coding, one for research/browsers, others for terminals, docs, or communication.

In practice, though, windows drift: new windows open on whichever Space you happen to be looking at, external monitors connect and disconnect, and apps spawn popups or extra windows on the wrong desktop. Before long, your clean layout becomes cluttered and you need to re-sort windows back onto the desktops where they belong.

2. Where Stock macOS Falls Short

No Native "Move to Desktop N" Key

macOS lets you switch to Desktop 1 or 2 with Ctrl+1 / 2, but offers no built-in shortcut to send the active window to a numbered Desktop.

Dragging Breaks Flow

The default workaround—opening Mission Control and dragging a window thumbnail onto another Space—requires taking your hands off the keyboard and hunting visually when you have many Spaces.

Spaces Shift Underfoot

By default, macOS reorders your Spaces based on recent use, which scrambles your mental map of where Desktop 1, 2, 3, etc. actually are.

No Public Apple API

Apple does not expose a public API for moving windows between Spaces, so reliable automation requires either hs.spaces, yabai, or Accessibility + CGEvent.

3. The Core Principles Behind This Tool

  1. Spatial Memory Over Visual Hunting: Desktop 1 and Desktop 2 should always represent fixed, predictable anchors in your workflow. When a window lands on the wrong Space, you shouldn't have to scan 5+ thumbnails to file it away.
  2. One-Keystroke Re-sorting: Focus a window, press ⌘ Cmd + 1 or ⌘ Cmd + 2, and it is immediately moved to Desktop 1 or Desktop 2. You can re-sort half a dozen stray windows in a few seconds.
  3. Choose Whether to Follow or Stay Put: Sometimes you want to move a window and switch to that desktop to keep working on it (FOLLOW_WINDOW = true). Other times you are tidying up your current Space and want to stay right where you are while tossing windows elsewhere (FOLLOW_WINDOW = false).
  4. No Unnecessary System Compromise: Start with Hammerspoon (no SIP disable required). Only reach for yabai + skhd if you already want a full tiling window manager.
Essential macOS Setting for Many Desktops If you use many Virtual Desktops and want to re-sort them predictably, go to System Settings → Desktop & Dock → Mission Control and turn OFF "Automatically rearrange Spaces based on most recent use". That guarantees Desktop 1, Desktop 2, Desktop 3, etc. stay in the exact order you expect.
