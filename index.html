macOS Mission Control Automation

Move Active Window to Virtual Desktop 1 or 2

macOS does not provide a built-in keyboard shortcut or public Apple API to send the focused window directly to a numbered Space. Here are your best options to bind ⌘ Cmd + 1 and ⌘ Cmd + 2 to move the active window to Desktop 1 or Desktop 2.

⌘ + 1 → Move active window to Desktop 1
⌘ + 2 → Move active window to Desktop 2
Important Hotkey Caveat Global ⌘+1 and ⌘+2 will override built-in app shortcuts (such as switching to Tab 1 / Tab 2 in Chrome/Safari or changing Finder view modes). If you want to keep those app shortcuts intact, swap cmd for ctrl + alt or cmd + shift in any of the configs below.

Comparison of Implementation Options

Option SIP Disable Required? Speed & Reliability Best For
1. Hammerspoon (Lua) No Fast, uses hs.spaces Most users — clean, free, scriptable, no SIP changes
2. yabai + skhd Partial SIP Disable Instant & native-feeling Power users who want a full tiling window manager
3. Native Swift CLI No Good (simulates titlebar drag + Ctrl+1/2) Minimalists who want zero third-party window managers
4. BetterTouchTool (GUI) No Instant Users who prefer a paid GUI app with no config files

Option 1: Hammerspoon (Recommended)

No SIP Disable • Free & Open Source

Hammerspoon is a lightweight macOS automation tool. Its hs.spaces module can move the focused window directly to Space 1 or Space 2 without disabling System Integrity Protection.

  1. Install Hammerspoon: brew install --cask hammerspoon
  2. Open Hammerspoon and grant Accessibility permission in System Settings → Privacy & Security → Accessibility.
  3. Save the script below to ~/.hammerspoon/init.lua (also in options/hammerspoon/init.lua) and click Reload Config.
-- ~/.hammerspoon/init.lua
local spaces = require("hs.spaces")
local window = require("hs.window")
local hotkey = require("hs.hotkey")
local alert  = require("hs.alert")

-- Set to true to follow the window to the target desktop; false to stay put
local FOLLOW_WINDOW = true

local function moveFocusedWindowToSpace(spaceIndex)
    local win = window.focusedWindow()
    if not win then
        alert.show("No active window found")
        return
    end

    local screen = win:screen()
    local screenSpaces = spaces.spacesForScreen(screen)
    if not screenSpaces or #screenSpaces < spaceIndex then
        alert.show("Desktop " .. spaceIndex .. " does not exist on this display")
        return
    end

    local targetSpaceID = screenSpaces[spaceIndex]
    spaces.moveWindowToSpace(win, targetSpaceID)

    if FOLLOW_WINDOW then
        spaces.gotoSpace(targetSpaceID)
    end
end

hotkey.bind({"cmd"}, "1", function() moveFocusedWindowToSpace(1) end)
hotkey.bind({"cmd"}, "2", function() moveFocusedWindowToSpace(2) end)

Option 2: yabai + skhd

Requires Partial SIP Disable

If you want instant, rock-solid window management across Spaces, yabai paired with skhd is the gold standard. Note that moving windows between Spaces with yabai requires partially disabling SIP in Recovery Mode and loading yabai's scripting addition.

  1. Install both tools: brew install koekeishiya/formulae/yabai koekeishiya/formulae/skhd
  2. Follow yabai's SIP setup guide and load the scripting addition (sudo yabai --load-sa).
  3. Add the bindings below to ~/.config/skhd/skhdrc (also in options/yabai-skhd/skhdrc) and start services with yabai --start-service && skhd --start-service.
# ~/.config/skhd/skhdrc
# Move active window to Desktop 1 or 2 and follow it:
cmd - 1 : yabai -m window --space 1 && yabai -m space --focus 1
cmd - 2 : yabai -m window --space 2 && yabai -m space --focus 2

# Or move silently without switching your current desktop:
# cmd - 1 : yabai -m window --space 1
# cmd - 2 : yabai -m window --space 2

Option 3: Native Swift CLI (Titlebar Grab + Ctrl+1 / Ctrl+2)

No SIP Disable • Zero WM Dependencies

macOS has a built-in trick: if you click-and-hold a window's titlebar and press Ctrl+1 or Ctrl+2, Mission Control carries that window to Desktop 1 or 2. This Swift binary automates that exact gesture using the Accessibility API and CGEvent.

  1. Enable Switch to Desktop 1 (Ctrl+1) and Switch to Desktop 2 (Ctrl+2) in System Settings → Keyboard → Keyboard Shortcuts → Mission Control.
  2. Compile options/swift-native/MoveWindowToSpace.swift: swiftc -O options/swift-native/MoveWindowToSpace.swift -o /usr/local/bin/move-window-to-space
  3. Bind Cmd+1 and Cmd+2 via skhd, Raycast, or macOS Shortcuts to run move-window-to-space 1 / 2.
// Compile & test from Terminal (grant Accessibility permission when prompted):
swiftc -O options/swift-native/MoveWindowToSpace.swift -o move-window-to-space
./move-window-to-space 1
Option 4: GUI App (BetterTouchTool) If you prefer not to maintain scripts or config files, BetterTouchTool has built-in actions called "Move Window to Space 1" and "Move Window to Space 2" that you can bind directly to ⌘+1 and ⌘+2 without disabling SIP.
