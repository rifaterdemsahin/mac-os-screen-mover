Step-by-Step Setup Guide

Install & How to Use

Get up and running in a couple of minutes. Pick one of the three installation methods below—Hammerspoon is recommended for most macOS users because it requires no System Integrity Protection (SIP) changes.

1. Prerequisites

Create at least 2 Desktops

Open Mission Control (Ctrl + ↑ or three-finger swipe up) and click the + button in the top-right corner so both Desktop 1 and Desktop 2 exist.

Grant Accessibility Access

macOS requires Accessibility permission to inspect or move windows. You will enable this under System Settings → Privacy & Security → Accessibility.

2. Choose Your Installation Method

Option 1: Hammerspoon (Recommended)

~2 min setup • No SIP disable
  1. Clone this repo and install Hammerspoon via Homebrew (or download it from hammerspoon.org):
brew install --cask hammerspoon
git clone https://github.com/rifaterdemsahin/mac-os-screen-mover.git
mkdir -p ~/.hammerspoon
cp mac-os-screen-mover/options/hammerspoon/init.lua ~/.hammerspoon/init.lua
  1. Launch Hammerspoon from Applications or Spotlight.
  2. Enable Accessibility: Open System Settings → Privacy & Security → Accessibility and toggle Hammerspoon on.
  3. Reload Config: Click the Hammerspoon icon in the macOS menu bar and select Reload Config.
Already have a ~/.hammerspoon/init.lua? Instead of overwriting with cp, append the contents of options/hammerspoon/init.lua to your existing init.lua file.

Option 2: yabai + skhd

Requires Partial SIP Disable
  1. Install yabai and skhd with Homebrew:
brew install koekeishiya/formulae/yabai koekeishiya/formulae/skhd
  1. Configure partial SIP following yabai's official SIP guide, then load the scripting addition:
sudo yabai --load-sa
  1. Copy the hotkey config and start both services:
git clone https://github.com/rifaterdemsahin/mac-os-screen-mover.git
mkdir -p ~/.config/skhd
cp mac-os-screen-mover/options/yabai-skhd/skhdrc ~/.config/skhd/skhdrc
yabai --start-service && skhd --start-service

Option 3: Native Swift CLI

No SIP disable • Zero WM dependencies
  1. Enable Mission Control shortcuts: Go to System Settings → Keyboard → Keyboard Shortcuts → Mission Control and enable Switch to Desktop 1 (Ctrl+1) and Switch to Desktop 2 (Ctrl+2).
  2. Compile and install the binary:
git clone https://github.com/rifaterdemsahin/mac-os-screen-mover.git
cd mac-os-screen-mover
swiftc -O options/swift-native/MoveWindowToSpace.swift -o /usr/local/bin/move-window-to-space
  1. Test from Terminal (grant Accessibility permission when prompted):
move-window-to-space 2
  1. Bind hotkeys: Use Raycast, macOS Shortcuts, or skhd to run move-window-to-space 1 on Cmd+1 and move-window-to-space 2 on Cmd+2.

3. How to Use

  1. Click any application window so it is the active (focused) window.
  2. Press ⌘ Cmd + 1 to send it to Desktop 1, or ⌘ Cmd + 2 to send it to Desktop 2.
  3. By default, your focus follows the window to the target desktop.

Common Customizations

  • Move silently without switching desktops: In ~/.hammerspoon/init.lua, change local FOLLOW_WINDOW = true to false. In ~/.config/skhd/skhdrc, remove && yabai -m space --focus 1.
  • Keep browser tab shortcuts (Cmd+1 / 2): Change {"cmd"} to {"ctrl", "alt"} in init.lua, or change cmd - 1 to ctrl + alt - 1 in skhdrc.
  • Add Desktop 3 or 4: Duplicate the hotkey.bind lines in init.lua with 3 / 4, or pass 3..9 to move-window-to-space.

4. Troubleshooting

Nothing happens when pressing Cmd+1 or Cmd+2 Make sure Hammerspoon, skhd, or your terminal/launcher app is enabled in System Settings → Privacy & Security → Accessibility. If you recently updated macOS or the app, toggle the checkbox off and back on.
"Desktop 2 does not exist on this display" Open Mission Control (Ctrl + ↑) and add a second Desktop on the display where the active window is located.
